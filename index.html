Ejemplos de progress y meter

Explora como usar las etiquetas <meter> y <progress> para mostrar valores y progreso de forma visual.

Etiqueta meter

La etiqueta <meter> se utiliza para mostrar un valor dentro de un rango conocido.

Se puede usar para representar niveles de batería, progreso de descarga, valoraciones y más.

Parámetros:

  • value --> Valor actual del medidor.
  • min --> Valor mínimo que puede alcanzar el medidor.
  • max --> Valor máximo que puede alcanzar el medidor.
  • low (Opcional) --> Umbral de valor bajo.
  • high (Opcional) --> Umbral de valor alto.
  • optimum (Opcional) --> Valor óptimo del medidor.

Etiqueta progress

La etiqueta <progress> se utiliza para mostrar el progreso de una tarea.

Parámetros:

  • value --> Valor actual del progreso.
  • max --> Valor máximo que puede alcanzar el progreso.

25% completado
